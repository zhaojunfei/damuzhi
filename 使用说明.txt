社保局店工资管理系统 - Web 版使用说明 (macOS)
================================================

【技术架构】
前后端分离 B/S 架构（浏览器访问，无需桌面客户端）
- 后端：FastAPI + SQLAlchemy + MySQL（端口 8000）
- 前端：Vue3 + Element Plus + ECharts（端口 5173）
- 数据库：MySQL 5.7（复用 Docker 容器 phpcms-db，端口 3306）

【启动方式】
双击「启动Web系统.command」，或终端执行：
  1. 确保 Docker 中 phpcms-db 容器在运行（已包含 MySQL）
  2. 后端：cd backend && SALARY_DB_USER=root SALARY_DB_PASS=root123 SALARY_DB_NAME=salary_system python3 main.py
  3. 前端：cd frontend && npm run dev
  4. 浏览器访问 http://localhost:5173

【登录账号】
超级管理员：admin / admin2555

【权限模型】
- 超级管理员：全局参数（部门/职务/职级补助/提成规则）统一维护、
  商铺管理、操作员管理、审计日志、可进入任意商铺
- 操作员：只能操作自己所属商铺的数据（员工/工资/发放），
  全局参数只读调用、不可修改

【全局参数（管理员统一维护，所有商铺共用）】
- 全局部门：生鲜部/百货部/收银部/后勤部（可增删，删除需密码2555）
- 全局职务+职务工资：店长(2000)/主管(1200)/收银员(300)/理货员(300)/小时工(0)
  维护时可设置该职务的职级补助，工资明细选员工时自动带出
- 提成规则：按职务配置绩效提成/销售提成，保存工资时自动联动

【功能模块】
1. 工作台 - 员工/在职数、最新月应发/实发、各月实发趋势图
2. 员工档案 - 身份证自动识别性别/年龄/生日，部门/职务下拉（来自全局参数），
   离职红色标记、在职排前
3. 工资明细 - 自动计算（加班/请假/旷工/外出/小计/总计/实发），
   按职务自动带职级补助和提成，复制整月，导出34列工资条CSV
4. 工资发放 - 按月查看，部门汇总+发放形式统计，导出CSV含汇总
5. 全局参数 - 部门/职务/职级补助/提成规则统一维护（仅超管）
6. 商铺管理 - 新增商铺、操作员管理、进入商铺（仅超管）
7. 统计分析 - 各店铺累计收入(应发/实发)柱状图、员工年龄分布饼图、
   人员状态分布、部门人员分布、各店铺收入明细表（仅超管）
8. 审计日志 - 所有操作记录（仅超管）

【自动计算规则】
计薪基数 = 基本+业绩+职级补助+节假日+绩效+销售提成
日工资 = 计薪基数 ÷ 当月天数；小时工资 = 日工资 ÷ 10
加班补助 = 加班工时 × 小时工资 × 2
请假扣款 = 请假天数 × 日工资
外出扣款 = 外出工时 × 小时工资
旷工扣款 = 旷工天数 × 日工资 × 1.5
实发 = 总计 - 扣款 - 社保代缴 - 个税
金额四舍五入取整

【删除授权密码】所有删除操作需输入：2555
